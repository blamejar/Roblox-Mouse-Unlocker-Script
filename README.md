# Universal Mouse Unlocker Script

A lightweight, keyless universal mouse unlocker utility for Roblox.

🎥 **YouTube Showcase:** [Watch Showcase Video](https://youtu.be/Q41XK8OKtwc)  
📜 **ScriptBlox:** [View on ScriptBlox](https://scriptblox.com/script/Universal-Script-Universal-Mouse-Unlocker-229230)

## Features
* Press **V** to toggle cursor unlock.
* Press **End** to completely destroy the script.
* First-person & Shift-Lock compatible without breaking state.
* Auto-execute safe & bug-free.
